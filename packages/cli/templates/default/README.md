# SuperPlugin Template for Framer

This is a template for using the Framer Plugin API in a TypeScript project.

## Quickstart

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Learn more about Plugins in Framer: https://www.framer.com/developers/plugins/introduction

See SuperPlugins Docs: https://superplugins.framer.website
